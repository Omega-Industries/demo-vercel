# Snake Game

A simple Snake game built with Next.js and hosted on Vercel.

## Live Demo

This app is deployed on Vercel. Add your production URL here:

`https://your-project-name.vercel.app`

## Features

- Classic Snake gameplay
- Keyboard controls with arrow keys or WASD
- On-screen controls for mobile and touch devices
- Score and best score tracking
- Pause, play, and restart controls
- Responsive design for desktop and mobile

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deployments

Vercel automatically builds and deploys the app from this repository.

To deploy manually, run:

```bash
npx vercel
```

For production:

```bash
npx vercel --prod
```
